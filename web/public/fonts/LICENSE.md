# Fonts

Brand fonts from creativebandit.studio, self-hosted (latin subset) so the app never calls out
to Google Fonts. All three are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which permits bundling them with software.

| File | Family | Source |
|---|---|---|
| `inter-var.woff2` | Inter (variable, 400–700) | Google Fonts |
| `archivo-var.woff2` | Archivo (variable width 62–125, weight 400–900) | Google Fonts |
| `space-mono-400.woff2`, `space-mono-700.woff2` | Space Mono | Google Fonts |
